## Quick Start Guide

### Tahap 1: Generate ZIP (Local)
```bash
cd "C:\Project Web Porto\SanitaCheck - Kampus Sehat Terintegrasi\SanitaCHECK-version1-kelompok-6"
php buat_zip.php
```

### Tahap 2: Upload ke Hosting
1. Upload `project.zip.001`, `.002`, dst. ke `htdocs/`
2. Upload `unzip.php` ke `htdocs/`
3. Akses `domain.com/unzip.php` → Extract

### Tahap 3: Setup & Configure
1. Buat database di Cpanel
2. Create `.env` file (copy dari `.env.example`)
3. Isi DB credentials
4. Upload `deploy-setup.php`
5. Akses `domain.com/deploy-setup.php` → Setup

### Tahap 4: Cleanup
Hapus file:
- `unzip.php`
- `deploy-setup.php`
- `buat_zip.php` (optional)

## Yang Sudah FIXED

### ✅ Missing Data Issues (Penyebab tombol tidak bisa diklik & halaman hilang)

**Masalah sebelumnya:**
- Folder `resources/views` mungkin di-exclude
- Controllers tidak lengkap
- Migration files tidak ada

**Sudah diperbaiki:**
1. **Critical folders SELALU diinclude:**
   - `app/` - Semua controllers
   - `routes/` - Route definitions
   - `resources/views/` - **Semua views (PENTING!)**
   - `database/migrations/` - **Semua migrations**
   - `config/` - Configuration files
   - `public/` - Assets & static files

2. **Better exclude logic:**
   - Hanya exclude vendor & node_modules (dependencies besar)
   - Hanya exclude tests & development files
   - Jangan exclude file penting untuk runtime

3. **Validation:**
   - Script akan report total files diinclude
   - Report file/folder yang di-skip
   - Error handling yang jelas

## Important Notes

⚠️ **DO & DON'T:**

| ✅ DO | ❌ DON'T |
|------|---------|
| Clear cache sebelum ZIP | Upload node_modules |
| Run npm build sebelum ZIP | Upload vendor folder |
| Upload semua .001, .002, dst | Upload project.zip utuh |
| Hapus unzip.php setelah selesai | Leave unzip.php di server |
| Use FTP untuk upload | Use file uploading di browser |
| Check storage/logs untuk error | Ignore error messages |
